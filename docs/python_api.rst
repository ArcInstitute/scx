Python API (``pyscx``)
======================

The ``pyscx`` package combines a compiled PyO3 extension (the bulk of the
public API — ``open``, ``ScxBackedSparseDataset``, ``TrainingPipeline``,
``IndexPlanDataset``, the ``pyscx.accel.*`` accelerators, etc.) with a
small set of pure-Python helpers and framework integrations.

The narrative reference for the full surface lives in :doc:`api` (rendered
from ``docs/api.md``). This page auto-generates entries for the
Python-side helpers and integrations.

.. note::

   The Rust extension module ``pyscx.pyscx`` is built by maturin and is
   not installed in the ReadTheDocs build environment. Symbols re-exported
   from it (``open``, ``ScxBackedSparseDataset``, ``TrainingPipeline``,
   ``IndexPlanDataset``, ``pyscx.accel.*``, …) are mocked during the
   docs build, so they don't appear here as autogenerated entries — see
   :doc:`api` for the canonical reference of those.
